# Facit för inspelningen till MES-246 (läs kortet innan handen släpper).
# Samma ordning som stegen i MANUS.md, som Jesper följer rakt av.
# En handling per rad, i ordning, uppdelat i turer som i ett riktigt parti.
# Ordlista:
#   <kort>                     läggs ned på en fri plats
#   <kort> tappad              läggs ned redan tappat (kommer in tappat)
#   <kort> hög A / hög B       läggs på landhögen (A = Swamp, B = Plains)
#   <kort> på <kort>           fästs vid kortet direkt (equipment under creaturen,
#                              förskjutet; auran så som Jesper brukar)
#   token <typ> (<som>)        en token läggs ut; <som> = vad som föreställer den
#   flytta <kort> till <kort>  ett kort som redan ligger flyttas och fästs under
#                              det andra kortet (equip om)
#   tappa / untappa <vad>      vrid kortet eller hela högen (bara det som står)
#   <kort> till graveyard      flyttas från bordet till graveyard-högen
#   <kort> från graveyard till spel   tas från graveyard-högen och läggs på bordet
#   <kort> från graveyard till handen tas från graveyard-högen och lyfts ur bild
#   <kort> från graveyard till exile  tas från graveyard-högen och läggs åt sidan, ut ur bild
#   <kort> till handen         lyfts från bordet, ut ur bild
#   <kort> överst i library    läggs från bordet överst på library, baksidan upp
#   mill 3                     tre kort från library till graveyard, ett i taget
#   bort <vad>                 lyfts bort ur bild (en token som dör)
# Alla kortnamn finns i dev/golden/lek.txt; tokens gör det inte.
