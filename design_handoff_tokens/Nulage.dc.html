Nuläge

Tokens dyker upp — men inte ur något

När Ancestral Blade eller Siege-Gang Commander läggs ut står tokens bara där bredvid, med samma gröna puls som varje nytt kort. Ingenting säger att det var kortet som skapade dem.

Ancestral Blade → 1 Soldier
Siege-Gang Commander → 3 Goblins

Idag: token läggs ut när kortets data hämtats och ritas med .nykort (nypuls, 1,4 s). Alla tokens kommer samtidigt.
